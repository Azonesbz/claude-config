# Étape 02 — Direction artistique

**Sortie attendue** : 3-5 références réelles avec URL, et les **tokens** écrits dans la feuille de chantier.

Sans tokens, chaque composant collé à l'étape 04 imposera **son** style : dix sections excellentes, dix identités différentes.

## Charger la doctrine

**Charger la skill `visual-references`** : où chercher, comment lire une référence sur six axes, comment en tirer des tokens, et le seuil d'accessibilité non négociable.

## Choisir les références

Chercher via les outils disponibles (WebSearch, WebFetch, navigateur) chez **Mobbin**, **Land-book**, **Godly**, **Awwwards**, **Refero**, et chez les **concurrents gagnants** du panel de l'étape 01 — ce sont eux le repère que la cible voit déjà.

- **3 à 5 références**, pas quinze : au-delà, la direction artistique devient un patchwork.
- **Chaque référence a une URL réellement consultée.** Ne jamais décrire de mémoire.
- **Registre cohérent avec le positionnement** : une direction artistique de luxe sur une offre à bas prix crée une dissonance qui coûte des conversions.
- **Faisabilité vérifiée** : une référence primée qui repose sur six mois de motion design n'est pas une référence, c'est un piège de planning.

## Produire les tokens

Écrire dans la feuille de chantier, avant toute ligne de style :

| Token | Contenu |
|-------|---------|
| **Palette** | Rôles sémantiques (fond, surface, texte, accent, bordure), pas des noms de couleurs. Deux couleurs identitaires suffisent |
| **Typographie** | 2 familles maximum, échelle, graisses, hauteur de ligne |
| **Espacement** | Une seule échelle, pour toute la page |
| **Formes** | Rayons, ombres, bordures |
| **Motion** | Durées et courbes — un seul vocabulaire |
| **Ton éditorial** | Trois adjectifs : il cadre le copy autant que le style |

## Accessibilité — non négociable

Contraste texte/fond **≥ 4.5:1** (≥ 3:1 grand texte), focus visible sur tous les interactifs, la couleur ne porte jamais seule l'information, `prefers-reduced-motion` respecté, corps **≥ 16 px** sur mobile. Le gris clair sur blanc est le défaut le plus courant des directions « épurées » — et il exclut des acheteurs.

## Restituer

Afficher le **moodboard dans le fil** : les références avec, pour chacune, **ce qu'on lui emprunte précisément** (« à celle-ci : le rythme vertical généreux et le contraste titre/corps »), puis les tokens. Afficher, **puis enchaîner** — pas de demande de validation.

## Porte

Les tokens sont écrits et complets. Toute valeur de style produite plus tard s'y réfère ; aucune couleur en dur.
